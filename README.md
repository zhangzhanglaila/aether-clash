# Python MOBA Prototype

一个纯 Python 标准库实现的 2D MOBA 原型，不需要安装第三方依赖。

## 运行

```powershell
cd D:\game\python_moba
python main.py
```

## 操作

- 启动后先选择 `中文` 或 `English`
- 进入大厅后先选择对战模式，再点击开始对战
- 选择英雄后会进入对战加载页，再开始对局
- `W A S D` 或方向键移动
- 鼠标移动瞄准
- 鼠标左键或 `Space` 普攻
- 按住 `Q / E / R` 显示技能范围指示器，松开按键释放
- 技能瞄准时也可以左键释放，右键取消
- `Q / E` 默认 1 级，`R` 需要英雄 4 级解锁
- 升级后获得技能点，按 `Z / X / C` 或点击技能按钮上方 `+` 升级 `Q / E / R`
- `Q` 小技能，不同英雄有直线、散射或近身范围效果
- `E` 位移、防御或辅助技能
- `R` 大招，冷却更长，伤害和范围明显高于普通技能
- `B` 回城，移动、攻击、放技能或受到伤害会打断
- `F` 闪现，`G` 治疗
- 回到己方水晶附近会出现商店，按 `1 / 2 / 3` 或点击装备购买
- 按住 `Tab` 查看双方等级、击杀/死亡、金币、装备和技能等级
- `Esc` 退出

## 可选英雄

- `Vanguard / 铁卫`：战士，血量高，Q 是穿透长矛，E 是冲锋并造成近身伤害，R 是指定区域爆发。
- `Star Ranger / 星弓`：射手，攻速和射程高，Q 是三连射，E 是长距离位移并重置普攻，R 是扇形箭雨。
- `Storm Arcanist / 雷法`：法师，身板脆但爆发高，Q 是大型穿透法球，E 是护盾治疗并震开近身敌人，R 是大范围雷暴。
- `Iron Sentinel / 玄甲`：坦克，承伤能力强，Q 是近身震荡，E 是强化防御和范围反击，R 是大范围守护重砸。
- `Night Shade / 影刃`：刺客，移速和爆发高，Q 是短距影切，E 是突进斩击，R 是锁定方向的处决爆发。

## 当前玩法

- 蓝方玩家英雄对战红方 AI 英雄
- 三路兵线自动推进
- 防御塔会自动攻击敌方单位
- 双方主水晶也会攻击靠近的敌方单位
- 摧毁敌方核心获胜
- 英雄死亡后自动复活
- 技能弹道可以命中敌方水晶，玩家方对建筑有额外伤害，节奏比初版更快
- 击杀小兵、英雄和防御塔会获得经验，升级会提升生命、攻击、射程和技能伤害
- 技能等级会提升对应技能伤害/治疗并缩短冷却，敌方英雄升级后也会自动加点
- 敌方英雄也会按模式获得经验并升级，等级会显示在头顶
- 商店装备包括攻击、移速和生命三类，每类最多升级 3 次
- 对局 HUD 包含小地图、计时器、比分、经验条和圆形技能按钮
- 战绩面板会显示双方等级、击杀/死亡、金币、装备等级和技能等级
- 普攻、技能命中、升级和摧毁建筑都有粒子和爆发特效
- 不同英雄技能有专属光线、位移拖尾、范围冲击和伤害飘字
- 击杀、升级和摧毁目标会出现战斗横幅提示
- 目前有 5 个可选英雄，覆盖战士、射手、法师、坦克和刺客
- 页面流程包含语言选择、大厅、英雄选择、对战加载和战斗 HUD

## 模式区别

- `水晶峡谷`：标准节奏，建筑和 AI 强度均衡。
- `训练营`：AI 更弱，开局等级和金币更高，兵线更慢，适合试玩。
- `快速对决`：兵线刷新更快，经验和金币更多，建筑更脆，节奏更快。

## 文件结构

- `main.py`：游戏状态、输入、战斗更新和绘制逻辑。
- `game_data.py`：英雄、装备、文本、本地化、实体模型和通用计算函数。
