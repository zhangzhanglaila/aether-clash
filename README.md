# Python MOBA Prototype

一个纯 Python 标准库实现的 2D MOBA 原型，不需要安装第三方依赖。

## 运行

```powershell
cd D:\game\python_moba
python main.py
```

## 操作

- `W A S D` 或方向键移动
- 鼠标移动瞄准
- 鼠标左键或 `Space` 普攻
- `Q` 直线穿透技能
- `E` 位移
- `R` 范围爆发
- `Esc` 退出

## 当前玩法

- 蓝方玩家英雄对战红方 AI 英雄
- 三路兵线自动推进
- 防御塔会自动攻击敌方单位
- 摧毁敌方核心获胜
- 英雄死亡后自动复活
