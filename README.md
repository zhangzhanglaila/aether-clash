# Python MOBA Prototype

一个纯 Python 标准库实现的 2D MOBA 原型，不需要安装第三方依赖。

## 运行

```powershell
cd D:\game\python_moba
python main.py
```

## 操作

- 启动后先选择 `中文` 或 `English`
- 然后选择英雄进入对局
- `W A S D` 或方向键移动
- 鼠标移动瞄准
- 鼠标左键或 `Space` 普攻
- `Q` 直线穿透技能
- `E` 位移
- `R` 范围爆发
- `Esc` 退出

## 可选英雄

- `Vanguard`：战士，血量高，Q 是穿透长矛，E 是冲锋并造成近身伤害，R 是指定区域爆发。
- `Star Ranger`：射手，攻速和射程高，Q 是三连射，E 是长距离位移并重置普攻，R 是扇形箭雨。
- `Storm Arcanist`：法师，身板脆但爆发高，Q 是大型穿透法球，E 是护盾治疗并震开近身敌人，R 是大范围雷暴。

## 当前玩法

- 蓝方玩家英雄对战红方 AI 英雄
- 三路兵线自动推进
- 防御塔会自动攻击敌方单位
- 摧毁敌方核心获胜
- 英雄死亡后自动复活
- 技能弹道可以命中敌方水晶，玩家方对建筑有额外伤害，节奏比初版更快
