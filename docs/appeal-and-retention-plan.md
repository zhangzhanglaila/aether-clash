# 吸引力与留存升级计划

本文档回答一个问题：为什么现在玩一把就不想玩了，以及怎么让它变成一个"想再开一把"的游戏。
配套文档：`polish-gap-analysis.md`（功能差距）、`hok-inspired-roadmap.md`（系统路线图）。

## 一、先泼冷水：关于"下载性感美女图 / 知名 IP 角色"这条路

结论：**不建议走这条路**，三个原因，按严重程度排序。

### 1. 版权与合规风险（硬伤）

- 知名 IP（动漫角色、王者荣耀/LOL 英雄、迪士尼等）的形象受著作权保护。把这些图放进仓库，GitHub 是公开托管，会被 DMCA 下架；仓库作者也可能被投诉。本项目现有文档已经明确"不复制第三方 IP"，换图等于推翻这条原则。
- 网上搜到的"美女照片"版权属于摄影师/模特/图库站。爬下来用 = 侵权，和 IP 图是同一个问题。
- 如果以后想发布到 itch.io、Steam 或任何平台，带未授权素材直接过不了审核。

### 2. 效果上的问题：贴图救不了画面

- 角色吸引力来自**风格统一的整套表现**：剪影、配色、动画、技能特效、立绘。单张照片贴在几何图形画布上会严重违和，效果比现在的矢量图形更差。
- 本项目渲染层是 tkinter Canvas 的 `create_oval / create_polygon`，没有精灵动画、旋转、逐像素透明。就算贴上高清立绘，对局里英雄仍然是一个会平移的圆。

### 3. 对"玩完一把就没兴趣"没有帮助

画面决定**前 5 分钟**的印象，玩法循环和成长感决定**接下来 5 小时**的留存。MOBA 的"再来一把"来自：这局差一点赢（再来一把）、新出装思路（再来一把）、升级解锁了什么（再来一把）。这些现状都没有。换图只解决第一个 5 分钟，而且解决得很勉强。

### 合规替代方案（同样有吸引力，零版权风险）

| 方案 | 来源 | 说明 |
| --- | --- | --- |
| 风格化原创角色（推荐） | Kenney.nl（CC0）、OpenGameArt、itch.io 免费素材、CraftPix 免费区 | 二次元/欧美卡通风格的原创战士、法师、射手素材包很多，风格统一 |
| AI 生成原创角色 | 自己用 AI 工具生成 | 生成**原创**角色（不要指定任何现有 IP 名字），自用无版权风险；立绘+精灵图都能生成 |
| 好看但有分寸的角色设计 | 同上 | 王者/LOL 的角色吸引力来自设计感和气质，不是裸露度。性感的风格化原创角色完全可行，真人照片则既侵权又违和 |

## 二、真正的问题诊断（基于当前代码）

现状：约 5100 行，11 个模块。**系统密度已经够高**（10 英雄、3 模式、三路兵线、塔、水晶、野区、装备、技能加点、AI 状态机、LAN 对战、双语 UI），`polish-gap-analysis.md` 也已经列了系统层面的差距。所以问题不在"功能少"，而在以下四层，按对观感的影响排序：

### 1. 视觉底座到顶了（根因）

全部画面由 tkinter Canvas 几何图元绘制。tkinter 的硬限制：

- 无精灵图/帧动画 → 英雄是圆+三角，小兵是点，动起来没有"活物感"
- 无逐像素透明、无旋转 → 特效只能是圆和线
- 无音频通道 → 游戏全程静音，打击感损失一半
- Canvas 图元数量上去后帧率明显下滑

这四条加起来，就是"看到画面没有什么吸引人的地方"的直接原因。**在 tkinter 里继续打磨，天花板就是现在这样。**

### 2. 打击感（juice）缺最后一档

已有的：粒子、伤害飘字、击杀横幅（`hok-inspired-roadmap.md` 记载）。这些已经是 tkinter 能做到的上限。还缺的（需要 pygame 才做得好）：

- 受击白闪、命中顿帧、屏幕震动、弹道拖尾贴图、技能特效精灵图、击杀特写
- 全套音效：普攻、命中、技能、击杀、推塔、金币、升级、BGM

### 3. 角色没有"人"

10 个英雄只有名字、定位、一个 accent 颜色。没有立绘、没有头像、没有体型差异（都是同样大小的圆）、没有技能图标。选人页和加载页因此毫无期待感。

### 4. 局外没有任何东西

打完一把：没有账号成长、没有任务、没有成就、没有解锁、没有皮肤、没有熟练度、结算页没有 MVP/称号。**没有任何一个钩子让玩家想开第二把。** 这是"玩完一把就没有兴趣了"的直接原因。

## 三、开发计划（四个阶段，可独立验收）

总原则：**先换底座，再补表现，再建留存，最后扩内容**。前一个阶段是后一个的前置。

### 阶段 0：迁移 tkinter → pygame-ce（约 1-2 周）【最高优先级】

这是所有视觉目标的硬前提，建议把 roadmap 里"最后迁移 pygame"提前到现在。

- **保留不动**：`combat.py`、`ai.py`、`game_data.py`、`economy.py`、`equipment_data.py`、`map_systems.py`（约 3400 行纯逻辑，与渲染无关）
- **重写**：`main.py` 游戏循环、`rendering.py`、`input_handler.py`（约 1700 行）
- **附带解决**：README 里"零第三方依赖"的卖点会失去，但那是学习项目的卖点，不是好玩游戏的卖点；在 README 里说明即可
- **验收标准**：功能与现在完全一致；稳定 60 FPS；英雄能用精灵贴图渲染；`pygame.mixer` 可用

### 阶段 1：素材管线 + 角色视觉（约 2-3 周）

- 建立 `assets/` 目录结构：`sprites/heroes/`、`icons/skills/`、`ui/`、`portraits/`、`audio/`
- 10 个英雄各配：立绘（选人页/加载页/HUD 头像）+ 对局精灵（idle/move/attack 至少各 2 帧）+ Q/E/R 技能图标
- 英雄体型差异化：坦克大一号、射手瘦长、刺客带残影贴图等
- 队伍区分用调色替换（同一素材蓝/红两套色）
- 小兵/野怪/塔/水晶同步换贴图
- 素材来源见第一节表格；先从 CC0 包里挑一套风格统一的打底，AI 生成补缺口
- **验收标准**：选人页有立绘网格，对局里没有一个是几何图形角色

### 阶段 2：打击感与音频（约 1-2 周）

- 受击白闪、命中顿帧（30-60ms）、屏幕震动（技能命中/被塔攻击/击杀）
- 弹道换成带拖尾的贴图；技能特效从圆圈换成精灵图序列
- 音效全套（freesound.org CC0 或 sfxr/jsfxr 生成）：普攻、命中、每个技能一个音、击杀、推塔、买装备、升级、倒计时、胜负；背景音乐 1-2 首
- 击杀播报升级：连杀横幅 + 特写短暂镜头
- **验收标准**：静音玩和开声音玩，手感差距巨大；这局"打人"有反馈了

### 阶段 3：局外留存循环（约 2-3 周）【直接针对"玩完一把就没兴趣"】

- 本地存档（json 即可）：账号等级与经验、金币货币
- 每日任务 3 个（"用射手赢一局""击杀 15 个小兵"之类），奖励货币
- 成就系统 20-30 个，大厅展示进度
- 皮肤系统：从换色皮肤做起（阶段 1 的调色管线直接复用，成本极低）
- 英雄解锁 + 英雄熟练度等级
- 结算页升级：MVP 评定、称号（"输出机器""推塔狂魔"）、本局数据回顾、经验/任务进度展示
- **验收标准**：一个新玩家连续玩 3 天，每天进游戏都有"今天有事做"的目标

### 阶段 4：内容与深度（长期，持续做）

- 英雄扩到 15+（roadmap 已有计划，沿用）
- 装备主动技能、完整合成树
- 地图事件：远古守卫 buff、刷新倒计时播报、争夺型中立目标
- AI 难度分级（人机排位感），不同英雄不同 AI 打法
- 设置页（音量、按键）、战斗记录

### 明确不做 / 暂不做

- ❌ 任何知名 IP 或网图素材（第一节的原因）
- ⏸ 3v3 / 5v5 与网络对战扩展（在留存问题解决前，多人化不解决任何问题）
- ⏸ 更复杂的连招系统（先让现有技能"看起来"和"听起来"像打中了人）

## 四、优先级一句话总结

**换 pygame（1）→ 换上合规素材让角色像"人"（2）→ 把打击感和声音补满（3）→ 建局外钩子留住人（4）→ 最后才扩内容。**

视觉素材解决"第一眼"，打击感解决"这一把爽不爽"，局外循环解决"下一把还想不想"。三件事缺一，另外两件都白做。
