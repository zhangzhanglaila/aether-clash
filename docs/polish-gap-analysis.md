# Aether Clash 细节差距分析与修复清单

本文档用于把当前 1v1 原型继续打磨成更完整的原创 MOBA。对照对象是成熟 MOBA 的功能层级和体验质量，不复制任何第三方 IP 的角色、美术、音效、文案、地图或具体数值。

## 总体判断

当前版本已经具备核心循环：语言选择、大厅、模式、选英雄、加载、对线、三路兵线、防御塔、水晶、野区、装备、等级、技能、AI、结算和 LAN 1v1。

主要问题不是“没有游戏”，而是大量系统停留在可用层：

- 信息展示不够：玩家不知道技能具体效果、装备具体加什么、模式到底差在哪里。
- 战斗反馈不够：升级、购买、命中、控制、推塔和资源刷新还缺更清晰的提示层。
- 决策深度不够：装备、野区、兵线、塔、敌方 AI 和胜利目标之间的联动还比较浅。
- 表现细节不够：英雄外观、技能特效、音效、镜头反馈、击杀播报和局内节奏还不够丰富。
- 系统规模不够：英雄、装备、地图机制、局外成长、多人对战、设置页和教程都还只是早期形态。

## 本轮已修复

- 加载页敌方英雄头像和名字不再写死为铁卫，会显示真实敌方英雄。
- 英雄选择页增加 hover 技能说明，Q/E/R 不再只有技能名。
- 模式卡增加规则摘要，直接显示兵线、金币、经验和建筑倍率。
- 顶部 HUD 增加敌方英雄名、等级和金币，方便判断敌我成长差。
- 商店卡片增加装备属性说明，购买后在英雄头顶显示属性变化。

## 优先级 1：1v1 对战手感

目标：让一局 1v1 更像完整对局，而不是功能演示。

- 英雄选择增加锁定确认、敌方预览、推荐定位和难度标记。
- 技能按钮增加技能名/冷却/升级收益提示。
- 普攻增加更明确的弹道、命中、暴击/强化攻击反馈。
- 塔攻击增加锁定线、预警圈和换目标提示。
- 水晶和防御塔增加受击阶段表现，例如低血量闪烁、护盾破裂、摧毁动画。
- 击杀、推塔、升级、购买和远古守卫刷新增加更强的播报层。

## 优先级 2：成长和装备

目标：让玩家能感知“升级、加点、出装”真的改变战斗力。

- 技能升级面板显示每级伤害、冷却和控制时长变化。
- 装备详情面板显示完整属性、合成要求、推荐原因和被动说明。
- 增加更多装备被动：减速、吸血、护盾、穿透、冷却、残血保护。
- 敌方 AI 也应购买装备，且不同模式有不同经济策略。
- 结算页显示伤害、承伤、经济来源、推塔、野怪和参团数据。

## 优先级 3：AI 和模式差异

目标：让敌方不只是移动靶，模式不只是倍率不同。

- 训练营：AI 更保守，给玩家更多补兵、打野和试技能空间。
- 水晶峡谷：AI 平衡发育、守塔、打野、推进。
- 快速对决：AI 更主动压线、争夺中心资源、加快结束。
- AI 需要根据英雄类型调整行为：射手拉扯、刺客绕后、坦克守塔、法师消耗。
- AI 需要能识别兵线、塔仇恨、低血量斩杀和回城时机。

## 优先级 4：地图与目标

目标：让玩家有对线以外的选择。

- 野区刷新需要倒计时提示和小地图标记。
- 中心远古守卫需要更明显的争夺价值，例如临时强化兵线或英雄增益。
- 草丛需要进入/离开提示、视野边界和敌方消失反馈。
- 增加原创大目标，例如星辉巨像，击败后获得推塔或兵线增益。
- 推掉高地塔后强化兵需要更明显的视觉区别和播报。

## 优先级 5：页面和局外系统

目标：让游戏不像单窗口 demo。

- 增加设置页：语言、音量、按键、画质/特效密度。
- 增加英雄详情页：定位、技能、推荐出装、上手难度。
- 增加对局教程：移动、普攻、技能、回城、购买、推塔、打野。
- 增加历史战绩和简单玩家资料。
- 增加局内暂停/退出确认。

## 优先级 6：表现层

目标：补足视觉和声音反馈。

- 技能特效需要按英雄区分颜色、形状、速度和命中表现。
- 增加按钮音、购买音、升级音、击杀音、推塔音和胜负音。
- 增加程序化或可授权音效，不使用第三方游戏资源。
- 英雄形象后续迁移到 `pygame` 后改为 sprite/动画帧。
- 局内 UI 需要更接近游戏 HUD：边缘信息密集，中央只保留关键反馈。

## 后续推荐执行顺序

1. 继续完善 1v1：技能说明、装备详情、AI 出装、击杀播报、塔预警。
2. 增加英雄到 8-10 个，每个英雄至少有明确连招和弱点。
3. 增加原创大目标和更完整野区收益。
4. 加音效和更细技能特效。
5. 再扩展 3v3 / 5v5。
6. 最后迁移到 `pygame`，重做 sprite、动画、音频和输入手感。
